Política de privacidad

Subscription Control es una aplicación de uso personal que se ejecuta únicamente en el ordenador de su propietario (Adrián Rufat). Última actualización: 29 de septiembre de 2026.

Datos a los que accede

Con el permiso gmail.readonly de Google, la aplicación lee en modo de solo lectura los correos de las cuentas de Gmail de su propietario que parecen recibos, facturas o avisos de renovación, para detectar suscripciones y pagos recurrentes. Nunca envía, borra, modifica ni marca correos.

Cómo se usan y almacenan

Los datos se procesan y se guardan exclusivamente en una base de datos local del propio ordenador del usuario. Las credenciales de acceso se guardan cifradas en el almacén de credenciales del sistema operativo. No existe ningún servidor externo de la aplicación.

Compartición con terceros

Los datos no se venden, no se comparten con terceros, no se usan para publicidad y no se utilizan para entrenar modelos de inteligencia artificial. No hay analítica ni seguimiento.

Uso de datos de las API de Google

El uso de la información recibida de las API de Google cumple la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

Revocar el acceso y eliminar datos

El acceso puede revocarse en cualquier momento desde la propia aplicación o en myaccount.google.com/permissions. Borrar la carpeta de datos de la aplicación elimina toda la información almacenada.
